# Cheat FPS 0.8.1

FastAPI + WebSocket 서버 판정, Three.js 클라이언트의 전체 실행 프로젝트다. 배포용 렌더러가 포함되어 Python 의존성만 설치하면 실행된다.

## 0.8.1 변경

- 1번 칼, 2번 권총, 3번 AR, 4번 산탄총. 5번 칸은 위에 수류탄 계열, 아래에 투척무기를 표시한다. 5를 다시 누르면 두 장비를 전환한다. 모바일은 무기창에서 각각 직접 누른다.
- 시작 화면에서 수류탄/섬광탄/화염병 중 하나, 도끼/투척 단검/수리검 중 하나를 고른다. 로컬 대기실에서는 각 참가자가 따로 변경하며 변경하면 준비가 취소된다. 시작 후에는 변경할 수 없다.
- 칼은 사거리 2.2m, 피해 70, 간격 0.45초의 무한 근접 공격이다. 탄피와 총구 화염이 나오지 않는다. 다른 탄약을 모두 쓰면 칼로 돌아간다.
- 도끼를 오른쪽 아래로 옮겨 65% 크기로 표시한다. 조준선에 어두운 외곽선·밝은 선·초록 중심점을 넣는다. PC 조작 설명은 시작 화면 오른쪽에 표시한다.
- 섬광탄은 시야가 닿는 최대 12m 내 상대와 자신에게 거리·보는 방향에 따라 최대 4초의 섬광을 준다. 체력을 깎지 않는다. AI도 섬광 중 사격하지 못한다.
- 화염병은 지면·벽 충돌 또는 3초 발동 시 8초 동안 반경 3m의 불을 만든다. 0.4초마다 20 피해, 엄폐 차폐와 자해를 적용한다. 아군 피해는 없다. Glowsquid의 제련소 장판 면역과 화염병은 별개다.
- 수류탄 계열은 모두 1/3. 누르고 준비·놓아서 투척, 준비부터 3초 발동을 공유한다. 무기 변경·사망·연결 종료 시 남은 시간으로 떨어진다. 화염병은 투척 후 물체에 닿으면 먼저 깨진다.
- 단검 1/4(피해 65), 수리검 5/15(피해 35). 발사 간격은 각각 0.7초/0.24초, 장전은 0.65초/1.1초다. 도끼는 기존 명중 반환·바닥 회수 규칙을 유지한다. 단검·수리검은 맞으면 소모되며 바닥에 남은 것은 주워서 회수할 수 있다.
- 새 장비의 1/3인칭 모델·투척 궤적·월드 모델·장전·실제 비행 잔상을 연결했다. 모든 맵은 약간 어둡게 조정하고 거리 안개를 강화했다. 새 칼날·장비 재질과 화염·불씨도 추가했다.

아래 이전 변경 기록에서 과거 슬롯·동작 설명이 다른 경우 현재 0.8.1 규칙과 무기 표를 따른다.

## 0.8.0 변경

- 위로 던진 도끼가 엄폐물 내부에 갇히지 않는다. 윗면에서는 접근 가능한 가장자리까지 미끄러져 바닥으로 내려간다. 회수 전에는 5번 칸의 도끼가 빨간색이며 직접 주워야 한다.
- 수류탄은 벽뿐 아니라 엄폐물 윗면에서도 튕긴다. 3D 연속 충돌로 빠른 투척의 관통을 막는다.
- AI가 점프·웅크린 상대의 몸통 높이를 반영해 조준한다. 반응 시간·오차·일반 시야는 유지하며 AI는 치트를 사용하지 않는다.
- 도끼나 수류탄을 장착하면 점선 예상 궤적과 도착 표식이 보인다. 실제 투척물에는 짧은 비행 잔상이 남는다. 예상 궤적은 현재 물체 위치로 계산하며 이후 이동한 기믹·캐릭터에 따라 결과가 달라질 수 있다.
- 수류탄은 발사 버튼을 누르면 안전핀을 뽑고 놓으면 던진다. 신관은 핀을 뽑은 순간부터 총 3초이며 손에서도 폭발한다. 준비 중 남은 시간은 탄약 표시 안에 보인다. 짧은 화면 탭은 즉시 투척이다.
- 모바일 체력·실드·탄약 행과 동작 버튼 행을 분리했다. 가로·세로·분할 화면에 각각 적용한다. 짧은 화면의 킬로그와 무기 선택창 높이, 시작 화면도 조정했다.
- 모든 맵에 엄폐물의 둥근 모서리, 금속 표면 마모·노멀·거칠기, 표면 명암을 적용했다. 캐릭터·무기도 같은 공통 재질을 사용한다. 항만 수면과 제련소 용융 철의 재질은 움직인다.
- 정적 지형을 재질별로 묶어 그리고 먼 캐릭터의 작은 부품을 생략한다. 열차·크레인·시침·깃발은 동적 상태를 유지한다. 자신의 점프 시점·웅크리기와 도끼 표시 위치를 부드럽게 갱신한다.
- 이동 중 카메라를 뒤로 끌던 위치 보정을 제한했다. 기믹 시계의 음수 보간을 막고, 느린 프레임에서도 받은 폭발 효과를 한 번은 표시한다.
- 버전·WebSocket 호환 확인·브라우저 캐시·메뉴 표시를 모두 0.8.0으로 맞췄다.

현재 그래픽은 원본 절차 생성 Three.js 자산이다. Source 엔진의 원본 아트·모션과 동일한 품질을 달성했다는 의미는 아니다. 실제 기기의 GPU 성능에 맞게 설정에서 품질을 조절한다.

## 이전 g2 동작·투척 업데이트

- 기본 점프 높이 1.10m. Scout 1.32m(+20%), Guard 0.99m(−10%), Glowsquid 1.10m다. 지상에서만 점프하며 키를 계속 눌러도 착지 후 자동 반복하지 않는다.
- 웅크리면 신장/시점/피격 범위를 65%로 줄이고 이동 속도는 보직 속도의 55%로 적용한다. 모바일은 각 화면의 점프 버튼과 웅크리기 토글을 사용한다.
- AR·권총은 머리 명중 시 2배 피해. 투척 도끼도 머리 명중 시 2배다. 산탄총·수류탄에는 헤드샷 배율이 없다. 헤드샷 처치에는 킬로그에 HEADSHOT을 표시한다.
- 투척 도끼는 1/0이며, 명중 반환 또는 바닥 회수 전에는 빨간 슬롯으로 표시하고 선택하지 못한다. 다른 무기도 탄창+예비탄이 모두 0이면 같은 규칙을 적용한다. 사용 가능한 다른 무기로 자동 전환한다. 선택 장비와 총기 탄약이 모두 비면 1번 칼로 전환한다. ∞ AMMO는 총기·선택 수류탄·단검·수리검에 적용하며 도끼 복제는 막는다.
- 총성에 발사 충격·저음·작동음·잔향을 별도로 합성하고 AR·권총·산탄총의 길이·주파수·무게감을 구분했다. 실총 녹음 파일을 사용한 것은 아니다.
- PC: Space 점프, 왼쪽 Ctrl 웅크리기, 좌클릭/G 공격. 2P: Numpad0 점프·오른쪽 Ctrl 웅크리기·Enter 공격. 기존 Space 공격은 점프로 변경했다.

## 앞선 g1 그래픽 변경

- 다섯 맵 모두 같은 외벽·창틀·창턱·배수관·옥상 설비 기준으로 주변 건물 8동을 구성한다. 엄폐물에는 컨테이너 골·잠금장치 또는 석재/제련소 패널 마감을 적용한다. 테마와 플레이 지형은 유지한다.
- 공통 재질의 과한 붉은 녹 얼룩을 줄이고, 다섯 맵에 같은 조명·그림자·반사 품질 기준을 적용한다. 모델별 색과 분위기는 테마에 맞춘다.
- 모든 무기에 손 보호대·장갑 마감과 개별 금속 디테일, 세 보직에 공통 장비 봉제선·장갑·부츠 디테일을 적용한다. 보직 능력과 외형 차이는 유지한다.
- 영광의 동상 중앙에 황금 인물상과 양면 매드해커스 깃발을 세운다. 깃발은 바람에 움직이고 한글 표시용 Noto Sans KR 글꼴 5글자를 번들에 포함한다. frontend/FONT-LICENSE.txt 참조.
- 실드는 HP 바로 옆의 청록색 가로 막대다. 0이면 완전히 숨기고 회복하면 다시 표시한다. 각 분할 화면과 관전 대상에 독립 적용한다.
- 렌더링 한 프레임의 예외가 이후 프레임 예약을 끊지 않도록 하고, 3D 렌더링 실패 시 Canvas 호환 화면으로 게임을 계속한다. 쉴드 100→75→0·회복·사망/관전을 검사한다. 사용자가 보고한 검은 화면은 일반적인 데스크톱 소진만으로 재현되지 않아 특정 기기의 원인까지 확인한 결과는 아니다.
- 깃발·열차 바퀴·팬을 정적 병합에서 제외하여 움직임을 보존한다. 현재 버전과 빌드 표시는 모두 0.8.1이다.

## 규칙 / 모드

최대 3vs3, 최대 5라운드 중 3승 선취. 한 팀 전원 HP 0이면 라운드 종료. 시간 종료는 생존자 수, 남은 HP 순으로 판정하고 완전 동률은 연장한다. 결과에는 라운드 승패·킬/데스·최종 점수를 표시한다.

- AI전: 보직 선택 후 바로 시작. 인간 1명과 아군 AI로 3명을 채우고 상대 AI 3명. AI는 치트를 사용하지 않는다. 빈 AI 자리는 팀에 빠진 보직부터 채운다.
- 로컬전: 같은 LAN 또는 배포 주소에서 방 코드로 참가. 양 팀 인간 각각 1명 이상, 참가자 전원 준비 시 자동 시작. 팀당 최대 3명이며 빈자리는 AI로 채우지 않는다.
- 같은 기기 2인 분할은 로컬 대기실에서 추가한다. 보직·준비·화면 조작을 각각 관리하며 둘 다 준비해야 한다.
- 서버 재시작 시 메모리의 방과 경기는 초기화된다. 다시 시작하거나 새 방을 만든다.

| 2 | 권총 | 12 / 120 | 0.27초 | 1.25초 |
| 3 | AR | 30 / 300 | 0.115초 | 1.5초 |
| 4 | 산탄총 | 6 / 36 | 1초 | 슬러그 1발당 0.7초 |
| 5 위 | 수류탄 / 섬광탄 / 화염병 중 선택 | 1 / 3 | 1초 | 다음 장비 준비 0.75초 |
| 5 아래 | 도끼 | 1 / 0 | 0.7초 | 바닥 회수 또는 캐릭터 명중 |
| 5 아래 대체 | 단검 | 1 / 4 | 0.7초 | 0.65초 |
| 5 아래 대체 | 수리검 | 5 / 15 | 0.24초 | 1.1초 |

도끼는 한 자루의 투척 무기다. 몸통 90 피해이며 중력과 지형 충돌을 적용한다. 다른 캐릭터에 맞으면 즉시 소유자 슬롯에 반환한다(아군 피해 없음). 바닥에 떨어지면 소유자가 1.25m 안으로 접근해야 자동 회수한다. 회수 전에는 빨간 슬롯으로 표시하고 선택을 막는다. 무한 탄창으로 복제되지 않는다. 권총은 31, AR은 25 피해다. 산탄총은 요청한 단일 슬러그 방식으로 근거리 100 피해·거리 감쇠가 있으며, 1발 이상이고 발사 대기가 끝났으면 장전 중 공격해 장전을 중단할 수 있다.

수류탄 1/3은 준비된 1개+예비 3개, 총 4개다. PC 좌클릭/G, 2P Enter 또는 화면의 발사 버튼을 누르면 핀을 뽑고 놓으면 던진다. 안전핀을 뽑은 때부터 총 3초 뒤 폭발한다. 1초 들고 던지면 약 2초가 남고 3초 들고 있으면 손에서 폭발한다. 짧은 화면 탭은 바로 던진다.

무기를 바꾸거나 사망·연결 종료 시에는 남은 신관을 가진 채 떨어진다. 무한 탄창도 신관을 없애지 않는다. 손에서 폭발한 뒤에는 버튼을 놓았다가 다시 눌러야 새 수류탄을 준비한다. AI는 같은 3초 신관으로 바로 던진다.

수류탄은 중력·윗면/바닥/옆면 튕김, 벽·열차·컨테이너·동상 충돌, 반경 6m·최대 160 피해·거리 감쇠·엄폐 차폐를 적용한다. 아군 피해는 없고 자신은 피해를 받으며 실드를 먼저 소모한다. 손에서 폭발해도 체력이 160보다 높은 보직이 무조건 즉사하는 규칙은 아니다.

총구 불꽃·탄피·탄창/슬러그 삽입·손동작·무기 교체와 상단 선택 HUD를 포함한다. 산탄총 발사 간격은 1초다.

## 치트

쿨타임·게이지 없이 토글하며 인간만 사용한다. 클래스 패시브와 별개다.

| 토글 | 동작 |
|---|---|
| AIM | 조준/공격 시 정면의 보이는 적 조준. 벽 뒤·아군·사망자 제외 |
| ESP | 벽 너머 상대 위치·이름·HP와 미니맵 표식 |
| NO RECOIL | 총기 사격 반동 제거 |
| ∞ AMMO | 총기/수류탄 소모·재장전 없이 공격. 발사/전환 간격 유지 |

무한 탄창은 잔탄 0에서도 작동한다. 끄면 켜기 전 유한 잔탄으로 돌아간다.

## 보직

기본 체력 기준 200. 서버가 능력을 판정하며 AI도 패시브를 갖는다.

| 보직 | HP | 이동속도 | 외형 / 능력 |
|---|---:|---|---|
| Scout | 150 | +20%, 9.6m/s | 날렵한 체형·경량 정찰 장비 |
| Guard | 300 | −25%, 6m/s | 넓은 체형·중장갑·바이저 |
| Glowsquid | 200 | +15%, 9.2m/s | 인간형 청록 장비, 제련소 화상 장판 면역 |

조준 시 기준 5.7m/s에 같은 배율을 적용한다. AI 기본 이동에도 보직 배율을 적용한다. Glowsquid 화면에만 화상 장판이 파란색이고 상대 ESP에는 청록/형광 노랑으로 점멸한다. 다른 총알·도끼·수류탄·기믹 피해는 받는다. 적 헬멧에는 빨간 띠가 있다.

경기 중 보직 변경은 불가하다. 로컬 대기실에서 변경하면 해당 참가자 준비를 해제한다. 체력바와 관전 HUD는 최대 HP와 실드를 사용한다.

## 로컬 실행

Python 3.11 권장. ZIP을 풀고 requirements.txt가 있는 폴더에서 실행한다.

```bash
python -m venv .venv
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

```bash
pip install -r requirements.txt
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --workers 1
```

같은 PC는 http://localhost:8000 . 같은 Wi-Fi의 다른 기기는 http://서버PC의LAN주소:8000 으로 접속한다. 서버 PC 방화벽에서 8000 포트를 허용하고 로컬 방 코드를 공유한다.

## Render

루트에 requirements.txt, render.yaml, .python-version, backend/, frontend/를 넣는다. ZIP 자체를 올리지 않고 압축 해제한 폴더 구조를 유지한다.

- Runtime: Python
- Root Directory: 비워 둠
- Build Command: `pip install -r requirements.txt`
- Start Command: 아래 한 줄을 한 번만 입력

```bash
uvicorn backend.main:app --host 0.0.0.0 --port $PORT --workers 1
```

render.yaml의 Blueprint도 같은 설정이다. 메모리에 방을 유지하므로 worker는 1개다. .python-version과 Blueprint는 Python 3.11.11을 지정한다. 기존 서비스 Environment의 PYTHON_VERSION도 확인한다. 파일 추가만으로 기존 환경 변수 값은 바뀌지 않는다.

연결한 GitHub 브랜치에 자동 배포가 켜져 있으면 커밋 후 배포한다. 완료 후 /health의 version/build와 메뉴/설정이 모두 0.8.1인지 확인한다. 서버 재시작으로 연결이 끊어지면 다시 시작한다. 교체 절차는 UPDATING.md 참조.
