# v0.6.0 변경 사항

- 적 헬멧에 붉은 띠를 표시한다. 분할 화면에서도 각 시점의 적에게만 표시하며 아군에게는 보이지 않는다.
- 킬로그에 불투명에 가까운 배경, 팀 색상과 무기/환경 사망 원인을 표시한다. 일반 화면 최근 4개, 작은 분할 화면 최근 2개를 표시한다.
- 항만 크레인은 착지 구역에 사람이 있어도 하강한다. 컨테이너 아래의 인간/AI는 HP 100 피해로 즉사하며 압사 로그가 남는다. 이전 버전의 착지 대기 동작을 제거했다.
- 제련소는 경기 시작 4초 뒤부터 8초마다 무작위 바닥 3곳을 선택한다. 반경 2.8m, 2초 예고 후 4초 활성화, 접촉 시 0.5초마다 25 피해. 스폰·피해·녹아웃은 서버에서 결정하고 좌표와 시간을 모든 클라이언트에 공유한다. AI도 위험 구역에서 벗어나려 한다.
- 1인칭 총기에 나사·그립 홈·배출구·가늠쇠 디테일을 추가하고 상단 무기 선택 아이콘을 교체했다.
- 원격 이동은 100ms 보간 버퍼와 최대 80ms 제한 예측, 장전/무기 교체는 프레임 시간에 따른 감쇠 보간을 사용한다. 장전 타이머도 서버 갱신 사이에서 진행시켜 계단식 동작을 줄였다. 네트워크·기기 성능에 따른 끊김을 완전히 없앤다는 보장은 아니다.

이하 이전 기록보다 위 v0.6.0 변경이 우선한다.

# v0.5.0 업데이트 요약

- 슬롯 1 AR(30/300), 슬롯 2 권총(12/120), 슬롯 3 산탄총(6/36). 숫자는 장탄/최대 예비탄이다. 라운드 시작에 보충한다.
- 산탄총은 발사 간격 1초, 한 발 장전 0.7초다. 1발 이상 장전되면 사격으로 장전을 중단한다. 비어 있으면 첫 탄 삽입을 기다린다. AR/권총은 탄창 교환, 산탄총은 붉은 탄피·황동 베이스의 슬러그탄을 한 발씩 넣는 모션이며, 한 번 발사할 때 단일 슬러그를 판정한다.
- 화면 ↻ 또는 F(2P O)를 누르면 상단 황금색 슬롯 HUD가 열린다. 슬롯을 탭해 선택하거나 다시 전환키를 눌러 순환한다. 키보드 1/2/3(2P 7/8/9)은 직접 선택. 치트는 Z/X/C 또는 화면 버튼이다.
- 견착 자세 수정, 적 총구 불꽃, 최대 96개의 재사용 탄피 효과. 탄피는 장식이며 충돌/피해가 없다.
- 항만: 바다·대형 화물선. 크레인이 20초 주기로 컨테이너를 이동한다(3초 경고·6초 이동). 두 착지 구역 중 목적지에 생존자가 있으면 하강을 기다린다. 이동에 맞춰 서버 충돌·시야·AI 경로와 클라이언트 충돌 지도가 갱신된다.
- 제련소: 주변 용융 철 웅덩이·슬래그·산업 설비. 바깥 배경은 플레이 구역 밖의 장식이다.
- 시계 광장: 중앙 탑 주위 시각별 12개 엄폐물. 시침은 24초에 한 바퀴, 접촉 피해 35·재피해 간격 1초다. 양 팀과 AI에 동일 적용한다.
- 천문관측소: 산악 배경과 회전 돔·망원경. 철도 기지는 기존 열차를 유지한다.
- 인간 이동 8m/s, 조준 5.7m/s. AI는 거리별 무기 선택, 유한 탄약 관리, 근거리 아군의 최근 목격 위치 공유, 시침 회피와 지형 변경 후 경로 재탐색을 수행한다. 치트는 쓰지 않는다.
- 새 상세 배경/모션은 WebGL2 렌더러용이다. Canvas 호환 모드는 간소화된 표시이며 서버 판정은 같다. 실제 iPad/S25 성능 검증은 별도 필요하다.

이하 실행 안내와 이전 버전 구현 기록을 함께 제공한다. 충돌하는 이전 설명보다 위 v0.5.0 규칙이 우선한다.

## 로컬 실행

Python 3.11 이상을 설치한 뒤 ZIP을 풀고 **requirements.txt가 있는 폴더**에서 실행한다.

### Windows PowerShell

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --workers 1
```

### macOS / Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --workers 1
```

브라우저에서 http://localhost:8000 을 연다. index.html을 직접 더블클릭하면 서버 연결이 없으므로 플레이할 수 없다. 서버는 Ctrl+C로 종료한다.

## AI전

1. 메인 메뉴에서 AI전을 선택하고 게임 시작을 누른다. 이름·캐릭터·치트를 미리 정하지 않는다.
2. 서버가 다섯 맵 중 하나를 무작위로 정한다. 대기방/방 코드/준비 완료 과정 없이 3초 카운트다운 뒤 경기로 들어간다.
3. 혼자 플레이하면 인간 1명 + 아군 AI 2명 vs 적 AI 3명이다.
4. AI전 시작 메뉴에는 2인 분할·캐릭터 선택·치트 설정이 없다. 치트는 플레이 중 토글한다.
5. AI는 아군과 적 모두 치트를 사용하지 않는다.
6. 결과 화면의 **AI전 다시 플레이**는 새 맵을 다시 무작위로 정하고 곧바로 새 경기를 시작한다. 같은 맵이 연속으로 나올 수도 있다.

## 다섯 맵

| 맵 | 랜드마크 | 동선 |
|---|---|---|
| 컨테이너 항만 | 중앙 갠트리 크레인 | 대칭 컨테이너 엄폐와 측면 통로 |
| 제련소 | 주황색 용광로·높은 굴뚝 | 세로 차폐벽 사이 우회로 |
| 시계 광장 | 네 방향 시계탑 | 중앙 광장과 기둥 옆 통로 |
| 천문관측소 | 관측 돔·망원경 | 분리된 측면 차폐와 중앙 돔 주변 |
| 철도 기지 | 움직이는 기관차·철길 | 통과 주기를 보고 선로 횡단 |

AI전은 매 경기 서버가 무작위로 선택한다. 한 경기의 모든 라운드는 같은 맵이며 재경기에서 다시 추첨한다. 로컬 대전은 방장이 접속 창에서 고르며 대기실에서도 바꿀 수 있다. 맵을 바꾸면 모든 참가자의 준비 상태가 해제된다. 참가자는 방장의 맵을 공유하며 경기 도중에는 바꿀 수 없다.

시작 화면은 실제 맵 5개를 12초 간격으로 순환하고 각 맵 주위를 천천히 둘러본다. WebGL2가 없으면 실제 격자의 등각 미리보기를 사용한다. 메뉴 미리보기를 위해 방을 생성하거나 AI 경기를 실행하지 않는다. `/arenas`가 서버의 맵 목록을 제공하며 게임과 미리보기가 같은 데이터를 사용한다. 생성 이미지 시안은 레이아웃 참고용이고, 실제 배경은 생성 이미지를 붙이지 않고 게임 지형으로 그린다.

## 로컬 대전 — 팀당 1~3명

1. 서버를 실행하고 메인 메뉴에서 로컬 대전 → 게임 시작을 누른다. 별도 접속 창에서 맵을 선택하고 방 만들기를 누른다.
2. 다른 참가자는 같은 와이파이/LAN에서 `http://서버PC의사설IP:8000`을 연다.
3. 방장이 알려 준 6자리 방 코드를 입력해 참가한다.
4. 각자 팀을 선택한다. 팀별 최대 3명, 방 전체 최대 6명이다.
5. BLUE와 RED에 각각 1명 이상 있고, 참가자 전원이 준비 완료하면 자동으로 카운트다운을 시작한다. 1대1·2대1 등도 가능하며 팀당 최대 3명/총 6명이다. 빈자리는 AI로 채우지 않는다.
6. Windows에서는 `ipconfig`, macOS에서는 네트워크 설정에서 서버 기기의 사설 IPv4 주소를 확인한다. 방화벽은 해당 사설 네트워크에서 TCP 8000 수신을 허용한다. 공유기의 게스트 네트워크/기기 격리는 연결을 막을 수 있다.

### 같은 기기에서 두 명

로컬 대전 접속 창에서 **같은 기기에서 2인 참가**를 체크한다. 키보드/마우스, 게임패드 또는 각 화면의 독립된 터치 조작으로 플레이한다. 같은 기기의 두 플레이어는 기본적으로 BLUE/RED에 한 명씩 배정되며 각자 준비 완료를 눌러야 자동 시작된다. 두 명만으로 1대1이 가능하다. 여러 기기를 함께 쓰면 기기 분할 여부와 관계없이 현재 참가자 전원이 준비해야 한다. 2인씩 3개 기기를 사용하면 3대3이 된다. 이 구현의 한 브라우저 분할 화면은 최대 2인이다. 6인 한 화면 분할은 지원하지 않는다. 일반 AI전 메뉴는 1인만 참가한다.

Render에 올린 뒤에는 같은 URL + 방 코드로 인터넷 대전도 가능하다.

## 조작

| 기능 | 1P | 2P |
|---|---|---|
| 이동 | WASD | 방향키 |
| 시점 회전 | 마우스 또는 Q/E | J/L |
| 발사 | 마우스 좌클릭 또는 Space | Enter |
| 조준 | 마우스 우클릭 또는 왼쪽 Shift | 오른쪽 Shift |
| 재장전 | R | P |
| 무기 순환: 소총 → 샷건 → 권총 | F | O |
| AIM / ESP / 무반동 | 1 / 2 / 3 | 7 / 8 / 9 |
| 관전 대상 전환 | V | V |
| 설정 | ESC 또는 우상단 메뉴 | 공통 |

게임 화면을 클릭하면 해당 플레이어의 마우스를 잠근다. 분할 화면에서는 클릭한 쪽의 시점을 조작한다. 브라우저에서 마우스 잠금을 지원하지 않으면 화면 드래그 또는 Q/E로 회전할 수 있다. 첫 클릭은 마우스를 고정하며, 그 뒤 좌클릭을 누르면 연사한다. 브라우저 오른쪽 클릭 메뉴는 게임 캔버스에서 차단한다.

게임패드: 왼쪽 스틱 이동, 오른쪽 스틱 좌우 회전, RT 발사, LT 조준, A 재장전, Y 무기 순환, 방향패드 상/하/좌로 치트 세 개를 토글한다. 브라우저에서 인식시키려면 게임패드 버튼을 한 번 누른다. 표준 Gamepad 매핑을 사용한다.

모바일:

- 각 화면 왼쪽 **아날로그 조이스틱**으로 이동한다. 가운데에서 멀리 밀수록 빠르게 움직인다.
- 빈 화면을 **짧게 탭**하면 1발 발사한다.
- 빈 화면을 **드래그**하면 좌우·상하로 시점을 회전한다. 드래그한 터치는 발사로 처리하지 않는다.
- **발사 버튼을 누르는 동안** 연사한다. 이동·회전·발사에 여러 손가락을 동시에 사용할 수 있다.
- 현재 총기 이름과 ↻가 있는 버튼은 무기 순환이다. 각 플레이어에게 독립된 무기 버튼이 있다.
- 조준 버튼은 토글, 장전 버튼은 재장전이다. 세 치트는 각 화면 아래에서 자유롭게 전환한다.
- 2인 분할의 각 화면에 조이스틱·발사·조준·장전·치트 버튼이 각각 있다. 가로 화면은 좌우, 세로 화면은 위아래로 나뉜다. 터치만으로 두 사람이 동시에 플레이할 수 있다.
- 버튼을 길게 눌러도 텍스트 선택·복사 팝업이 뜨지 않도록 iOS 선택/콜아웃과 기본 제스처를 차단했다.
- 손가락을 떼거나 터치가 취소되거나 탭이 비활성화되면 입력을 해제한다. 모바일에서는 가로 화면을 사용하면 시야가 넓어진다.

## 경기 규칙

- 팀당 최대 3명(AI전 3대3, 로컬은 팀당 1~3명), 최대 5라운드, 먼저 3승한 팀이 최종 승리한다.
- HP 100, 인간 소총 피해 25, AI 피해 16, 아군 피해 없음.
- HP 0이면 해당 라운드에서 즉시 탈락하고 살아 있는 아군을 관전한다. 라운드 중 부활하지 않는다.
- 3초 준비 → 120초 경기 → 라운드 종료 4초 → 다음 라운드 순서로 진행한다.
- 한 팀 전원 녹아웃 시 즉시 상대 승리.
- 120초 시간 종료 시 생존자 수, 팀 총 HP 순으로 비교한다. 모두 같으면 30초씩 연장하여 무승부 없이 최대 5라운드 규칙을 유지한다.
- 결과 화면에 모든 라운드 승자/이유, 최종 점수, 킬/데스를 표시한다.
- AI전은 결과에서 즉시 재경기한다. 로컬 대전은 방장이 대기실로 돌아가 재편성한다.
- 경기 중 연결이 끊기면 해당 자리를 치트 없는 AI가 이어받는다. 이미 탈락했다면 다음 라운드부터 활동한다. 재접속 시 진행 중인 자리를 되찾는 기능은 없다.
- 대기실에서 방장이 나가면 다른 인간 참가자가 방장을 이어받는다. 인간이 모두 나가면 방이 삭제된다.
- 설정 창을 열어도 다른 참가자와 AI 경기는 계속된다. 내 입력만 정지한다.

## 3종 공식 치트

| 토글 | 효과 |
|---|---|
| AIM | 조준·일반 발사·터치 탭 발사 시 정면 약 ±54도 내 보이는 적의 몸통으로 조준을 보정한다. 조준 버튼 없이 발사해도 적용된다. 벽과 지나가는 기차에 가려진 적은 제외한다. |
| ESP | 벽 뒤 적의 윤곽 박스·이름·HP 표시. 레이더는 시야 밖 적도 표시한다. |
| NO RECOIL | 서버의 연사 탄퍼짐/반동 증가를 제거한다. |

AIM은 조준 또는 발사할 때 작동하며 HUD에 대기 안내와 AIM LOCK 표시가 나온다. AI는 AIM을 사용하지 않는다. 무한 탄약은 제거했고, 총기에 따라 30/6/12발 탄창을 사용하고 재장전한다. 탄창별 잔탄은 무기를 바꿔도 유지한다. 치트는 대기실과 경기 중 자유롭게 켜고 끈다. 게이지·사용 횟수·쿨타임은 없다. 총 자체의 발사 간격은 존재한다. 캐릭터 외형은 scout / warden / rogue 세 종류다.

## 서버/동기화

- 서버 시뮬레이션 약 60Hz, 상태/입력 전송 약 30Hz. 화면은 requestAnimationFrame으로 갱신한다.
- 내 시점은 입력 즉시 반영한다. 내 이동은 클라이언트에서 예측한다. 서버가 적용한 입력 번호와 시간을 확인해 미반영 입력만 재계산하고, 화면상 보정 오차는 부드럽게 줄인다. 다른 캐릭터는 75ms 버퍼로 위치·방향을 보간한다.
- 이동에 가속/감속과 아날로그 입력을 적용했다. 대각선 속도가 더 빨라지지 않는다.
- 3D 캐릭터와 벽은 인스턴스 렌더링으로 묶어 그린다. 캐릭터는 다리 관절을 움직이며, 헬멧·얼굴·방탄복·장비·소총이 있다. 1인칭 소총·샷건·권총은 조준·반동·재장전·발사광을 표현한다. 샷건의 펌프, 권총의 슬라이드와 탄창도 움직인다. WebGL2가 없는 기기에서는 기존 Canvas 호환 그래픽을 사용한다.
- 화면 탭은 별도의 발사 요청으로 전송하므로 누름/뗌 메시지가 같은 서버 프레임에 도착해도 사라지지 않는다. 중복 요청은 무시하고 총의 발사 간격은 유지한다.
- 클라이언트는 전진/좌우/시선 방향/사격 입력을 전송한다. 좌표·피해·킬·승패를 직접 정하지 않는다.
- 서버가 이동 속도, 벽 충돌, 시선, 사격 간격, 탄창, 재장전, 히트, 녹아웃을 계산한다.
- 적 위치는 ESP 구현을 위해 상태에 포함된다. 경쟁용 은닉/안티치트 제품이 아니라 공식 치트 게임이다.
- 입력이 0.4초 이상 끊기면 이동/발사를 정지한다. 큰 패킷과 과도한 메시지를 제한한다.
- 이동은 바닥 평면에서 이루어지고 점프는 없다. 상하 조준은 시점과 서버 명중 판정에 모두 적용된다. 캐릭터끼리는 이동을 막지 않는다.
- 방/점수는 메모리 저장이다. 서버 재시작·배포 시 초기화된다. 한 프로세스/한 인스턴스로 운영한다. 다중 worker 또는 수평 확장을 켜면 서로 다른 방 메모리로 접속할 수 있으므로 사용하지 않는다.
- 계정·랭킹·영구 저장은 이 기획 범위에 포함하지 않는다.

## Render 배포

프로젝트 **폴더 안의 내용**을 GitHub 저장소 루트에 올린다. ZIP 파일만 올리는 것이 아니라 압축을 푼 소스가 있어야 한다.

### Blueprint 사용

1. Render에서 New → Blueprint를 선택한다.
2. 소스가 있는 GitHub 저장소를 연결한다.
3. 루트의 render.yaml을 적용하고 배포한다.
4. 완료 후 생성된 HTTPS 주소를 연다.

### Web Service 수동 설정

- Runtime: Python 3
- Build Command: `pip install -r requirements.txt`
- Start Command: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT --workers 1`
- Health Check Path: `/health`
- Python version: `3.11.11` (render.yaml의 PYTHON_VERSION)
- Static Site가 아니라 **Web Service**로 생성한다.

프론트엔드와 WebSocket을 동일한 서비스에서 제공하므로 별도 백엔드 URL이나 API 키를 설정할 필요가 없다. HTTPS 접속에서는 클라이언트가 자동으로 wss://를 사용한다. 무료 서비스의 유휴 중단 뒤 첫 접속은 시작 시간이 필요할 수 있다. 배포/인스턴스 교체 시 연결 중인 경기는 종료된다.

공식 문서:
- https://render.com/docs/deploy-fastapi
- https://render.com/docs/websocket

## 철도 기지의 기차

- 경기 시간 기준 24초 주기로 같은 방향으로 통과한다. 처음 3초는 경고등과 HUD로 진입을 예고한다. 라운드 준비/종료 중에는 움직이지 않는다.
- 선로 중앙(y=17.5m), 폭 4m·길이 12m의 기관차가 초당 5.6m으로 이동한다. 사람이든 AI든 충돌하면 100 피해를 받아 즉시 녹아웃된다. 아군/적군 구분이나 치트 면역은 없다.
- 서버가 이동 구간과 캐릭터 이동을 함께 검사한다. 빠른 통과나 지연된 프레임에서도 충돌을 놓치지 않으며, 기차가 맵 밖으로 사라졌다 돌아오는 순간에는 맵 전체를 가로지르는 가짜 충돌이 생기지 않는다.
- 기차 사망은 데스와 킬 로그에 기록되고 다른 플레이어에게 킬을 주지 않는다. 남은 아군 관전과 전멸 승패 판정을 적용한다. 양 팀 전원이 동시에 탈락하면 점수 없이 같은 라운드를 다시 시작하며 사망 통계는 유지한다.
- 통과 중인 기관차는 총알과 일반 시야를 막는다. 기차가 없을 때는 선로를 건널 수 있다. ESP는 기존 규칙대로 사용할 수 있다.
- 서버 시계를 WebSocket으로 전송하고 화면에서는 프레임마다 기차를 보간한다. 시작 화면의 철도 기지 미리보기에도 움직이는 기관차가 나온다. WebGL2 미지원 환경은 Canvas로 움직이는 기차를 표시한다.

충돌 피해와 주기 등은 `backend/arenas.py`의 railway.train 값으로 바꿀 수 있다. 다른 네 맵에는 기차가 없다.


## 60×35m 확장과 AI 이동

다섯 맵 모두 가로 60m·세로 35m다. 격자 한 칸과 플레이어 위치 한 단위는 1m이며, Three.js·Canvas·사격·충돌·기차가 같은 좌표를 사용한다. 렌더링만 늘리지 않고 이동 가능한 지형을 다시 구성했다. 캐릭터와 총기 크기는 유지했고 v0.5.0 인간의 이동 속도는 초당 8m(조준 5.7m)다. 스폰은 좌우 진영의 세 지점이며 모든 몸체가 지형과 겹치지 않는다.

맵마다 17~18개 엄폐 구역과 중앙 랜드마크를 배치했다. 항만은 컨테이너 사이 세 갈래 접근로, 제련소는 세로 차폐벽과 설비 우회로, 광장은 기둥과 광장 둘레 동선, 관측소는 연구동과 돔 주변 통로, 철도 기지는 선로 양옆 엄폐와 횡단로를 사용한다. 모든 이동 가능 칸은 연결되어 있다. 철도 기차는 같은 물리 속도로 더 긴 선로를 통과하도록 24초 주기로 바뀌었다. 충돌은 100 피해다.

AI는 측면 진입·중앙 전진·순찰 성향을 나눠 시작하고, 전투 중 횡이동·엄폐·재배치·후퇴를 섞는다. 가까이 몰린 아군과 간격을 벌리고 막히면 경로를 다시 정한다. 사격은 점사와 짧은 휴지기를 번갈아 사용한다. 보이는 적에게만 정상 속도로 시점을 돌리며, 적을 놓치면 마지막 목격 위치를 잠시 수색한다. 벽 뒤 적의 실시간 위치를 추적하지 않는다. 선로 경고나 가까운 기차에는 선로 바깥으로 피한다. AI는 세 가지 치트를 모두 사용하지 않는다.


## v0.3.0 그래픽

다섯 맵에 512×512 원본 절차 생성 재질을 적용한다. 콘크리트·아스팔트·돌·벽돌·금속·도장 철판·천·피부·고무의 색상/노멀/거칠기 맵과 유리 재질을 사용한다. 표면의 미세 요철·녹·마모, 환경 반사, ACES 톤 매핑, 방향광 그림자와 접지 그림자, 테마별 하늘과 거리 안개를 표현한다. 제련소와 관측소에는 보조 조명이 있다.

엄폐물은 서버의 기존 1m 격자를 사각 구역으로 묶어 같은 위치와 높이로 그린다. 손잡이·문 잠금봉·환기구·경고판·배관·조명·낡은 바닥 표시를 추가했고, 경기장 바깥에는 창문·굴뚝·전선이 있는 건물 배경을 배치한다. 지형과 장식은 재질별로 합쳐 그린다. 기관차와 바퀴는 움직이는 부모 그룹을 유지한다.

캐릭터는 둥근 관절·얼굴·헬멧 부속·고글·장비끈·손가락을 사용한다. 총기는 둥근 모서리, 배출구·방열구·조작부·탄창 홈·방아쇠울·장갑 디테일, 금속 재질, 발사광 조명과 회전 시 작은 관성 움직임을 표현한다. 성능과 명중 판정은 외형에 따라 달라지지 않는다.

| 품질 | 표현 | 해상도 |
|---|---|---|
| 높음 | 2048 그림자·캐릭터 실루엣 그림자·보조 조명 | 최대 기기 픽셀비 1.5 |
| 보통(기본) | 1024 지형 그림자·캐릭터 접지 그림자·보조 조명 | 최대 픽셀비 1, 부하에 따라 55~100% 자동 조절 |
| 낮음 | 재질·모델·접지 그림자 유지, 방향광 그림자/보조 조명 끄기 | 기본 70%, 부하에 따라 추가 조절 |

자동 해상도 조절은 3D 화면에만 적용하며 HUD와 터치 버튼의 크기·위치는 유지한다. 그래픽은 WebGL2 환경에서 적용한다. Canvas 호환 모드는 기존 간소화 표현이다. 텍스처와 구조물은 이 프로젝트의 코드로 만들며 실행 중 외부 자산을 내려받지 않는다. 하프라이프 2의 낡은 산업 시설 분위기를 참고했으며 원작과의 동일한 품질을 검증한 결과는 아니다. 실제 모바일 성능은 기기마다 다르다.


## v0.3.1 기관차

철도 기지의 기관차를 2대차·4축 디젤 기관차로 바꿨다. 8개 차륜과 저널박스·스프링·브레이크, 운전실 유리·와이퍼·좌석, 엔진 점검문·라디에이터 그릴·회전 팬, 안전 난간·발판·연결기·공기 호스·전후 등화가 있다. 차체 재질은 큰 녹 얼룩 대신 작은 마모와 도장면을 사용한다. 레일 단면과 침목·체결구·자갈도 다시 구성했다. 외형은 특정 실차를 복제하지 않은 산업용 디젤 기관차다.

길이 12m·폭 4m의 기존 이동/충돌 범위와 초당 5.6m·24초 통과 주기를 유지한다. 역 맵의 기존 엄폐물·AI·피해/라운드 판정은 바뀌지 않는다. 원본 변경 파일은 `frontend/locomotive.js`, `frontend/scene3d.js`와 다시 빌드한 `frontend/renderer3d.js`다.


## v0.4.0 플레이어·무기·전체 맵

인체 실루엣을 다시 구성했다. 테이퍼 몸통·팔다리, 턱/이마가 이어진 머리, 작은 이목구비, 위장복·장갑·부츠·방탄복·장구류를 사용한다. 양손과 무릎은 두 관절 역기구학으로 계산한다. 이동 거리와 전진/후진/옆걸음 속도에 따라 발 디딤과 무릎 굽힘을 만들며, 조준 상하각·피격·사격·장전 자세를 반영한다. 녹아웃은 즉시 탈락 판정을 유지하고 약 0.55초 쓰러짐 후 5초간 시체를 표시한다. 시체는 충돌 장애물이 아니다. 절차적 관절 모델이며 스캔 인물·모션 캡처·물리 래그돌은 아니다.

| 무기 | 탄창 | 발사 간격 | 재장전 | 인간 피해/유효 거리 |
|---|---:|---:|---:|---|
| AR | 30 / 예비 300 | 0.115초 | 1.5초 | 25 / 65m |
| 산탄총 | 6 / 예비 36 | 1초 | 1발당 0.7초 | 단일 슬러그 최대 100, 7m 이후 거리 감쇠 / 28m |
| 권총 | 12 / 예비 120 | 0.27초 | 1.25초 | 31 / 42m |

모든 총은 버튼을 누르고 있으면 해당 발사 간격으로 반복 사격한다. 샷건은 1회에 탄약 1발을 소모하고 단일 슬러그를 판정한다. 각각 가장 가까운 보이는 적에만 맞으며 벽·열차를 관통하지 않는다. 무반동을 켜도 슬러그 고유의 작은 탄퍼짐과 권총 고유 오차는 유지한다. AIM은 현재 총기의 유효 거리 안에서 작동한다. AI의 기본 무장은 소총이며 치트는 사용하지 않는다. v0.5.0부터 예비탄은 AR 300발, 권총 120발, 산탄총 36발로 제한한다.

전환에는 0.35초가 걸리며 이전 총기의 남은 발사 대기는 없애지 않는다. 장전 도중 바꾸면 장전을 취소하고 기존 잔탄을 유지한다. 라운드 시작 시 세 탄창을 모두 보충한다. 모바일 장전은 일회성 서버 명령이므로 긴 렌더링 프레임 때문에 짧은 버튼 입력이 사라지지 않는다.

다섯 맵 모두 같은 재질/그림자/하늘/주변 건물 파이프라인을 사용한다. 항만은 크레인 트러스·운전실·호이스트·사다리, 제련소는 굴뚝 보강 링·설비·난간·점검구, 광장은 석재 줄눈·코니스·창·지붕 이음매, 관측소는 돔 패널·개폐구·망원경 마운트·서비스 설비를 추가했다. 철도 기지의 디젤 기관차와 레일은 유지한다. 기존 60×35m 충돌 격자와 엄폐 배치는 바꾸지 않았다.
